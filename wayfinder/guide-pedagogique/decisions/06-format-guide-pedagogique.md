# Décision #6 : Format du guide pédagogique humain

## Date
2026-07-29

## Décisions

| Sujet | Décision |
|-------|----------|
| Format | Fichier unique `GUIDE_PEDAGOGIQUE.md` à la racine du repo |
| Audience | Développeur qui veut ajouter un guide pour son projet+framework |
| Contenu | Contexte, prérequis, structure d'un guide, étapes de création, check-list, référence rapide, exemple ProTask+AdonisJS |
| Relation skill | La doc explique le pattern indépendamment du skill. Le skill peut s'y référer. |
