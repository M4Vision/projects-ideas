# Critères de validation du pilote AdonisJS

## Question

Quels scénarios de lecture et de réalisation prouvent que le pilote AdonisJS aide réellement le lecteur à construire, comprendre et modifier ProTask sans se perdre ?

## Blocking

- [Stratégie des états complets du code](./003-strategie-etats-code-guide.md)
- [Vérification et diagnostic par leçon](./004-verification-et-diagnostic-par-lecon.md)

## Resolution comment

Le pilote est considéré comme réussi lorsqu'un débutant, avec le seul guide, peut : démarrer sans deviner, construire chaque bloc en validant les tests partiels, expliquer les choix grâce aux quiz, puis retrouver les bons fichiers pour réaliser une petite modification autonome. Les blocages observés doivent être rattachables à une leçon précise afin d'améliorer le parcours.
