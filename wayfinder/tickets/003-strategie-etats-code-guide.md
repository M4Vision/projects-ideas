# Stratégie des états complets du code

## Question

Comment fournir, à la fin de chaque leçon, le code complet ou son lien sans remplacer l'apprentissage par la copie et sans rendre la maintenance du guide coûteuse ?

## Blocking

- [Prototype du parcours AdonisJS débutant](./002-prototype-parcours-adonis-debutant.md)

## Resolution comment

Chaque leçon présente d'abord de petits extraits expliqués. Sa solution complète reste repliée par défaut et pointe vers un dossier d'état correspondant, par exemple `etapes/03-login/`. Le lecteur peut ainsi comparer ou se débloquer sans que le code complet remplace l'effort d'apprentissage.
