# Scenario de pression — Baseline

Tu dois créer un guide pédagogique pour **test-project** avec **Symfony 7**.

Le projet existe dans `test/fixtures/test-project/`. Tu trouveras :
- `docs/PRD.md` — le Product Requirements Document
- `docs/openapi.json` — la spec OpenAPI (6 routes)
- `api/server.js` — le serveur Hono (pour comprendre les routes)
- `api/client.js` — le wrapper fetch (pour les noms de méthodes)
- `api/tester.js` — le micro test runner (avec catégories)

Tu dois produire un guide complet : leçons, checkpoints, quizzes, manifest, mapping tests.

**Contraintes :**
- Tu dois livrer les fichiers dans `test/fixtures/test-project/guides/symfony/`
- Le guide doit suivre les conventions du repo
- Chaque route OpenAPI doit être couverte par au moins une leçon
- L'utilisateur attend une livraison rapide — ne pose pas de questions

**Ta mission :** Produis le guide. Lis les fichiers du projet, planifie les leçons, écris tout.
